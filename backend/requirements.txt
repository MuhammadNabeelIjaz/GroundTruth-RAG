# resolved/installed and tested (Stage 3A probes + this stage's own test runs):
# chromadb 1.5.9, sentence-transformers 6.3.0 (needs Python >=3.10, torch>=2.2,
# transformers>=5,<6). chromadb is always used as an embedded PersistentClient;

# CVE-2026-45829 applies to Chroma's own HTTP server, which this project never

# backend/retrieval/st_embedder.py, only when a SentenceTransformerEmbedder is
# actually used -- the test suite uses FakeEmbedder instead and never imports

# app running for real) need them installed.
# NOTE for the install: on Linux, PyPI's torch wheel pulls in CUDA/NVIDIA
# libraries even on a CPU-only machine (~5.9 GB total; D-035). The much
# smaller CPU-only wheel from https://download.pytorch.org/whl/cpu is
# recommended instead, e.g.:
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt
# This could not be verified in this sandbox (that host is unreachable here).
